# N/P/K 三肥罐四泵系统实施说明

## 当前执行结构

模型把农艺处方换算成 N、P、K 三种母液的目标体积，ESP32-S3 负责现场闭环执行：

1. N、P、K 三组泵可同时启动；
2. 1、2、3 号流量计分别累计 N、P、K 母液；
3. 任一路达到自己的目标体积后立即停止对应泵，不影响另外两路；
4. 三路全部达量并停止后，才允许启动混合罐出口泵；
5. 故障、人工停止或控制器重启时，四路泵全部保持关闭。

三个肥罐默认定义如下：

| 肥罐 | 目标养分 | 示例浓度 |
|---|---|---:|
| N 罐 | N | 100 g/L |
| P 罐 | P2O5 | 80 g/L |
| K 罐 | K2O | 120 g/L |

示例浓度只用于软件仿真，上机前必须在 [hardware.json](configs/hardware.json) 中填写母液实测浓度和三只流量计的标定系数。如果一种母液同时含多种养分，则不能按独立 N/P/K 罐直接换算，需要改用养分浓度矩阵求解。

## 液路拓扑

```text
N 肥罐 -> 1 号流量计 -> N 泵 -> 混合罐
P 肥罐 -> 2 号流量计 -> P 泵 -> 混合罐
K 肥罐 -> 3 号流量计 -> K 泵 -> 混合罐
                                      |
                                      +-> 混合罐出口泵 -> 灌溉主管
```

每条肥路应配过滤器、止回阀、防虹吸装置和手动截止阀。流量计建议装在对应泵的入口上游；若实际泵型要求出口计量，应以流量计厂商的安装直管段、压力和方向要求为准。

## 状态机

```text
IDLE
  -> DOSING：N/P/K 按各自目标同时计量，分别停泵
  -> OUTLET：三路肥泵全部停止后，启动混合罐出口泵
  -> COMPLETE：出口泵到达设定运行时间后停止

任意阶段 -> FAULT/STOPPED：四路泵立即关闭
```

## 必须保留的联锁

- 任一肥泵启动后 8 秒无对应流量脉冲：四路泵全部关闭并报警；
- 任一肥路累计量达到目标：立即关闭该路泵；
- 投料阶段超过 30 分钟：四路泵全部关闭并报警；
- N/P/K 任一泵仍在运行时：禁止混合罐出口泵启动；
- 出口泵单次任务最长 7200 秒，手动运行最长 180 秒；
- ESP32 重启后四路继电器默认关闭，不恢复中断任务；
- 现场必须保留独立物理急停、漏保、空开和合适额定值的接触器。

## 雨量

翻斗雨量计默认接 ESP32-S3 GPIO18，按干接点脉冲累计，初始换算系数为 0.3 mm/次。RS485 雨量计也可以并入现有总线；RK3506B 优先读取 RS485 雨量，读不到时自动采用 ESP32 上报的翻斗累计雨量。
