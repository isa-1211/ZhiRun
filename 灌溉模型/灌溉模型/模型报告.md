# 呼和浩特水肥一体化V2模型报告

## 模型性质

V2是环境驱动的多输出策略模型：以单个土壤探针水分直接阈值、四种作物分阶段N/P/K预算和安全联锁为教师策略，结合真实天气与现场传感器输入，训练ExtraTrees同时预测每亩水、纯N、P₂O₅和K₂O。现场入口接收 CO2、土壤温度、单探针土壤水分、有效土壤 N/P/K、光照、雨量和 pH；土壤关键字段缺失或异常时禁止自动决策。

它不是产量模型。没有本地“水肥处理—产量/品质”标签，当前无法证明增产效果或求解真实最优处方。

## 数据与划分

| 项目 | 内容 |
|---|---|
| 天气 | NASA POWER呼和浩特2015—2025逐日温度、湿度、风、降雨、辐射 |
| 派生天气 | FAO-56 ET₀、未来2日降雨/温度/湿度/风速/光照摘要、7日雨量/ET₀、14日积温、连续干旱天数 |
| 土壤 | 运行时仅使用现场传感器的单探针水分、pH 和有效 N/P/K |
| 作物 | 马铃薯、甜菜、玉米、向日葵及生育阶段 |
| 传感器情景 | 单探针土壤水分、土温、空气温湿度、CO2、风速、光照、24 h雨量、EC、土检等级、已施肥量 |
| 总样本 | 39,600 |
| 训练集 | 2015—2022 |
| 验证集 | 2023 |
| 独立测试集 | 2024—2025 |

## 独立测试结果

| 输出 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 水量 m³/亩 | 0.3397 | 1.1947 | 0.9748 |
| N kg/亩 | 0.0343 | 0.1434 | 0.8529 |
| P₂O₅ kg/亩 | 0.0212 | 0.0862 | 0.8690 |
| K₂O kg/亩 | 0.0233 | 0.1293 | 0.7863 |

灌溉开关判断准确率为93.15%。模型外仍设置物理安全门：墒情/降雨不通过则禁止灌水；主水不运行、EC超限、施肥间隔不足、土检为高或阶段预算用完时，相应肥阀禁止开启。

## 使用边界

现场决策会把未来两天预报摘要映射进模型特征；高温和高 ET₀ 会对单探针水分的阶段
触发值做有限幅度上调，预报降雨会做下调，且始终受安全上下限约束。这是
基于预测的规则自调节，不是使用产量反馈的在线强化学习；天气预报失真时仍需依赖
土壤湿度、EC、pH、风速和人工急停等硬安全门。

训练样本仍是区域历史天气与农艺规则生成的基线，不能替代本地田间验证。上线前必须标定单个土壤探针、母液浓度、N/P/K 三只独立流量计、主管压力与流量范围。积累本地产量和品质标签后，应训练V3产量响应/多目标优化模型，并按整年份和整地块独立测试。
