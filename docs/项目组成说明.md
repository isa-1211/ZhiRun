# 智润农田水肥与水泵控制项目组成说明

## 系统组成

项目由 RK3506B 触控主机、ESP32-S3 水泵控制器、RS485 传感器、公网服务和水肥决策模型组成。

- RK3506B 通过 Modbus RTU 采集传感器，并在 LVGL 屏幕上展示完整参数。
- RK3506B 通过以太网或 Wi-Fi 向公网服务上报数据并获取控制命令。
- ESP32-S3 负责 N/P/K 三路流量闭环、四路继电器、出口泵顺序联锁和故障全关。
- 公网服务负责实时数据、历史记录、命令队列、Web 控制台和模型推理。

## 传感器参数

当前数据模型包含 12 个环境量：空气温度、空气湿度、CO2、光照、土壤水分、土壤温度、土壤 pH、氮、磷、钾、风速和雨量。

## 数据链路

```text
RS485 传感器 -> RK3506B -> 公网服务 -> Web 页面
                         -> LVGL 本地屏幕

Web 页面 -> 公网服务 -> RK3506B -> USB 串口 -> ESP32-S3 -> 四路继电器/泵组
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `edge/rk3506_collector.py` | RS485 采集、数据上报和 ESP32 命令转发 |
| `hmi_demo/` | RK3506B 的 LVGL 本地监控界面 |
| `esp32_pump_controller/` | ESP32-S3 水泵固件 |
| `server/` | 公网 API、Web 控制台和推理入口 |
| `灌溉模型/灌溉模型/` | 水肥决策模型、配置和测试 |
| `deploy/` | 公网服务与 RK3506B 启动脚本 |
| `.env.rk3506.example` | 边缘控制器配置模板 |

## 运行边界

RK3506B 负责采集和通信，ESP32-S3 负责实际执行，公网服务负责持久化和决策。真实令牌、Wi-Fi 密码和 SSH 凭据不得提交到仓库。
